# Coding Team Virtual League Strategy Meeting

## Overall Strategy
- Can change between states using time conditions
    - Can consider stored boxes
- Hunting offensive strategy
    - Have a hunting "intensity" which decreases with time
        - Greater intensity leads to more frequent hunts
        - Lower intensity results in lower frequency hunts
- Defending strategy
    - Safest strat is to stay with the box
- Box ID used to identify boxes
    - All in the docs
    - Only get your six boxes
- Using purple box to build a high tower at the start
- Positioning system
- Hunting and knocking are two main states
    - As game progresses, hunting "intensity" reduces leading to more knocking

## Hunting
### Searching

    - Consider proximity to highrises

## Knocking
### Searching
- Using camera to search for opposition boxes
### Pursuing
- Tracking the box to knock it away for a highrise or zone

## Main Program Loop
- Will operate in cycles
    - At the end of each cycle, a condition check is made and this decides the next state
    - An interrupt may occur to end the cycle prematurely
- Factors affecting state decisions
    - Interrupts (Built-in error-catching)
    - Time spent in last state
    - Time to end
    - Boxes in local area (Both friendly and opposition)
- Whoever is working on this section will need to come up with a way to use these factors to make decisions (consult the gc for ideas if need help)
- Will also need to figure out a statemachine implementation
